# Introduction to Python

## 1. What is Python?

Python is a **high-level, interpreted, general-purpose programming
language** known for its simple syntax and readability.

A programming language lets us communicate instructions to a computer.

### Example: Calculate the total price of two products

``` python
price1 = 100
price2 = 200

total = price1 + price2

print(total)
```

**Output:**

``` text
300
```

## 2. Why Do We Use Python?

-   Easy to learn and understand.
-   Simple and readable syntax.
-   Large collection of libraries and frameworks.
-   Supports Object-Oriented Programming (OOP).
-   Cross-platform compatibility.
-   Strong community support.

## 4. Features of Python

1.  **Interpreted:** Python code is executed by the Python runtime.
2.  **Dynamically typed:** We do not need to explicitly declare a
    variable's data type.
3.  **Object-oriented:** Python supports classes and objects.
4.  **Cross-platform:** Python runs on Windows, Linux, and macOS.
5.  **Open source:** Python is freely available to use.
6.  **Extensive libraries:** Python provides built-in modules and a
    large ecosystem of third-party packages.

## 5. Your First Python Program

``` python
print("Hello, World!")
```

**Output:**

``` text
Hello, World!
```

## 6. Basic Python Learning Sequence

Use this sequence to build your Python foundation:

1.  **Introduction to Python** --- What Python is, its features, and its
    applications.
2.  **Variables and Data Types** --- `int`, `float`, `str`, and `bool`.
3.  **Operators** --- Arithmetic, comparison, logical, and assignment
    operators.
4.  **Conditional Statements** --- `if`, `elif`, and `else`.
5.  **Loops** --- `for` and `while`.
6.  **Data Structures** --- Lists, tuples, sets, and dictionaries.
7.  **Functions** --- Parameters, arguments, return values, and scope.
8.  **Object-Oriented Programming** --- Classes, objects, attributes,
    and methods.
9.  **Exception Handling** --- `try`, `except`, and `finally`.
10. **File Handling and Modules** --- Reading and writing files, and
    importing modules.
